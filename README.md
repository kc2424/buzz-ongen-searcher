# バズ音源サーチャー

TikTok / YouTube Shorts で流行りそうな音源を探すための、ローカルで動くツール。

## 使い方

`run.bat` をダブルクリックするだけ。ブラウザが自動で開く。
終了するときは、黒い画面（コマンドプロンプト）で `Ctrl+C`。

**毎日1回起動するのが大事。** 起動するたびにその日のランキングが記録され、
記録が貯まるほど「昨日より○位上がった曲」が正確に出るようになる。

## 画面

| タブ | 内容 |
|---|---|
| 🔥 急上昇 | 前回の記録から **5位以上** 上がった曲＋新しくランクインした曲 |
| 📈 ランキング100 | 日本の最新トップ100 |
| 🔍 曲を検索 | 曲名・アーティスト名で検索。100位内なら順位も出る |

各カードでできること:

- ジャケット画像クリック → **30秒試聴**
- `TikTok` ボタン → その曲名でTikTok検索を開く（実際にどう使われているか確認できる）
- `Shorts` ボタン → YouTubeでその曲＋`#shorts` を検索
- `推移` ボタン → 順位の推移グラフ（記録が2日分以上あるとき）

## データはどこから来ているか

APIキー不要・公式のものだけを使っている。登録も課金も不要。

| 用途 | 取得元 |
|---|---|
| ランキング100 | Apple Music 日本 トップソング RSS |
| 試聴・ジャケット・検索 | iTunes Search / Lookup API |

### TikTokの数字を直接取っていない理由

2026年時点で、TikTokの公式API（Research API / Content Posting API）には
**トレンド音源を取得するエンドポイントが存在しない**。
非公式スクレイピングは規約がグレーで、すぐ壊れるうえ有料なので使っていない。

代わりに「TikTokでバズった曲は日本のストリーミングチャートに跳ね返る」性質を利用し、
チャートの**順位変動**からバズを検出している。
実際のTikTokでの使われ方は `TikTok` ボタンで自分の目で確認する、という設計。

## 中身

```
run.bat      起動用
server.py    サーバー本体（Python標準ライブラリのみ、pip install 不要）
index.html   画面
buzz.db      順位の記録（SQLite・自動生成）※消すと履歴が消えるので注意
```

## 調整したいとき

`server.py` の先頭にある定数を変えるだけ。

```python
BUZZ_THRESHOLD = 5    # 何位以上上がったら「急上昇」とみなすか
FRESH_DAYS     = 30   # リリース何日以内なら「新譜」バッジを付けるか
PORT           = 8765 # ポートが他とぶつかるときだけ変更
```

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| 黒い画面に「取得に失敗しました」 | ネット接続を確認。過去の記録は見られる |
| 試聴が鳴らない | 曲によってプレビューが無い場合がある。▶が出ていなければその曲は非対応 |
| 二重に起動してしまった | 2つ目は正しく動かない。黒い画面を1つ残して他は閉じる |
| 履歴を最初からやり直したい | `buzz.db` を削除して起動し直す |
